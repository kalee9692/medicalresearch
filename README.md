# medicalresearch (옛 주소 안내 전용)

이 저장소에는 **안내 페이지 한 장**만 있습니다. 홈페이지 소스코드가 아닙니다.

## 왜 있나

회사 홈페이지는 2026-08-06에 **https://medicalresearch.co.kr** (Cloudflare Workers)로 옮겼습니다.
그런데 옛 주소 `https://kalee9692.github.io/medicalresearch/` 가
**회사소개서 QR 안내 PDF·명함·이미 발송한 메일**에 실려 나가 있습니다.

그래서 옛 주소로 들어온 사람을 새 주소의 같은 위치로 넘겨주기 위해 이 저장소를 **공개(public)** 로 남겨 둡니다.
(GitHub Pages 는 무료 계정에서 공개 저장소만 동작합니다.)

## 실제 홈페이지 소스는 어디에

**비공개 저장소 `kalee9692/medicalresearch-site`** 로 옮겼습니다. 이 저장소가 아닙니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 옛 주소 접속 → 새 주소로 이동 |
| `404.html` | 옛 하위 주소(`/faq.html` 등) 접속 → 새 주소의 같은 위치로 이동 |

경로·검색어·앵커(`?`, `#`)를 그대로 붙여 넘깁니다.
